라이브러리 외부에 있는 js 파일을 import 하려고 시도할 때 나는 오류 입니다.

```bash
yarn add next-transpile-modules
```

```javascript
// next.config.js
const withTM = require("next-transpile-modules")([
  "drei",
  "three",
  "postprocessing",
  "<라이브러리>",
]); // pass the modules you would like to see transpiled

module.exports = withTM();
```
